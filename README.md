# bedrock-bench

Reproducible, fair benchmarks for Minecraft Bedrock servers.

`legacy/` holds the harness exactly as it was used for Endstone 0.11.14's
[BENCHMARK.md](https://github.com/EndstoneMC/endstone/blob/main/BENCHMARK.md): the Windows and Linux runners, the
third-party server adapters, the LeviLamina adaptation, the Go load bot and the result summaries. It is being refactored
into a clean, documented harness.
